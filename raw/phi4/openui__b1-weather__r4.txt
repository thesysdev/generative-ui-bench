```openui
root = Card([currentWeather, outlook, sunriseSunset], "sunk")

currentWeather = Card([weatherHeader, temp, conditions])
weatherHeader = CardHeader("Current Weather", "Bengaluru")
temp = Heading("23°C", "h3")
conditions = Tag("Partly Cloudy", null, null, "neutral")

outlookHeader = CardHeader("3-Day Outlook", "Bengaluru")
outlookDates = ["Today", "Tomorrow", "Day After"]
outlookTemps = ["24°C", "26°C", "25°C"]
outlookConditions = ["Sunny", "Cloudy", "Rain"]
outlook = Table([outlookDate, outlookTemp, outlookCond])
outlookDate = Col("Date", outlookDates)
outlookTemp = Col("Temperature", outlookTemps)
outlookCond = Col("Condition", outlookConditions)

sunriseSunsetHeader = CardHeader("Sunrise and Sunset", "Bengaluru")
sunrise = Heading("06:00 AM", "h3")
sunset = Heading("06:30 PM", "h3")
sunriseSunset = Card([sunrise, sunset])

```

This code defines a structured UI using `openui-lang` for a weather briefing screen, showing the current temperature and conditions for Bengaluru, a 3-day weather outlook, and sunrise and sunset times.
