```openui
root = Card([taskCard], "card", "column", "none", "center", "center", false)

taskCard = Card([taskHeader, taskStatus, markDoneButton], "card", "column", "none", "center", "center", false)

taskHeader = CardHeader("Urgent Task", "Deadline: Tomorrow")

taskStatus = Callout("info", "In Progress", "This task is currently in progress.")

markDoneButton = Button("Mark as Done", ["markAsDone"], "primary")

```

This code defines a single screen with a focus view for one urgent task. It includes:

1. A `CardHeader` displaying the task title and its deadline.
2. A `Callout` showing the task's current status.
3. A `Button` to mark the task as done.
